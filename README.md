# cola-health-

## 食藥記錄

首頁「記錄食藥」或設定 → 健康 →「食藥記錄」可新增、查看、修改及刪除已服用藥物的記錄。

- 記錄藥名、實際份量、單位（ml、mg、g、滴、粒、包、次）、食藥日期／時間及備註。
- 按日期瀏覽歷史；編輯保留原本日期／時間。今日紀錄亦會顯示於首頁時間線。
- 資料儲存於 D1，沿用專案的單一寶寶資料模型。
- 本功能記錄實際服藥資料，不會計算建議劑量或安排食藥提醒。

部署新版 Worker 後，首次存取食藥紀錄或時間線會自動建立 `medications` 資料表及時間索引。這是新增資料表的遷移，不會改動既有紀錄；新安裝亦可使用 `npm run db:init` 建立本機資料庫。

### 驗證

```sh
npm ci
npm test
npx wrangler deploy --dry-run
```

`npm test` 使用獨立的 Miniflare D1 測試資料庫，涵蓋舊資料庫遷移、食藥紀錄 CRUD、香港時間跨日查詢、時間線排序及輸入驗證，不會存取正式資料。

## 藥物敏感

首頁「藥物敏感」或設定 → 健康 →「藥物敏感」可記低曾經令寶寶過敏或有不良反應的藥物，方便家人（尤其長輩）睇醫生或買藥時出示。

- 只需填藥名；反應（可選多項）、嚴重程度、發生日期及備註均可留空。
- 一頁顯示全部敏感藥物，字體及按鈕較大；撳一下修改，向左掃或於表單內刪除。
- 有記錄時，首頁會顯示敏感藥物名稱；記錄食藥時如藥名吻合，表單會提示先問醫生或藥劑師。
- 資料儲存於 D1 `drug_sensitivities` 資料表，部署後首次存取時自動建立，不會改動既有紀錄。
- 本功能只作記錄及提醒，不提供醫療建議。
